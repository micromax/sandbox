# 11 — v0.3.0: Performance, Streaming Output & Dependency Management

## Overview

Milestone v0.3.0 expands `github.com/micromax/sandbox` with three production capabilities:
1. **Persistent Wazero Compilation Cache & Micro-Benchmarks**: Cross-process compilation caching dropping cold-start latency from ~3.4s down to ~280ms.
2. **Dual-Channel Output Streaming & Server-Sent Events (SSE)**: Real-time stdout/stderr streaming into `io.Writer`, callbacks, terminal CLI, and an HTTP SSE endpoint.
3. **Guest Package & Dependency Management**: Content-addressed host package cache (`packages.Store`), pure-Python wheel extraction into `/in/site-packages`, and CLI package management.

*(Note: Additional Language Packs for Ruby, PHP, and C# are deferred to a subsequent milestone per development agreement).*

---

## Deliverables & Architecture

### 1. Persistent Wazero Compilation Cache (`backend/wasm`)
- File-backed compilation cache initialized via `wazero.NewCompilationCacheWithDir(DefaultCacheDir())` storing native module code in `~/.cache/micromax-sandbox/wazero-cache`.
- Options: `WithCompilationCacheDir`, `WithInMemoryCompilationCache`, `WithCompilationCache`.
- Dedicated benchmark suite in `benchmarks/benchmarks_test.go`:
  - QuickJS execution: ~54 ms / op
  - Lua 5.4 execution: ~11.6 ms / op
  - High concurrency: 8-way concurrent parallel execution verified.

### 2. Real-Time Output Streaming & SSE (`sandbox`)
- **Dual-Channel Limit Writer**: `limitbuf.Writer` simultaneously records to an internal bounded buffer up to `Limits.MaxOutput` while streaming live chunks to `io.Writer` and/or `OnStdout`/`OnStderr` callbacks.
- **Spec Extensions**:
  - `StdoutWriter io.Writer`, `StderrWriter io.Writer`
  - `OnStdout func([]byte)`, `OnStderr func([]byte)`
- **HTTP SSE Handler**: `sb.SSEHandler()` serving real-time events (`start`, `stdout`, `stderr`, `done`, `error`) over `text/event-stream`.
- **MCP Server Notifications**: Live `notifications/message` chunks emitted during `execute_code`.
- **Live Terminal CLI**: `sandbox run` streams stdout and stderr directly to `os.Stdout` and `os.Stderr` in real time when `--json` is false.

### 3. Guest Package & Dependency Management (`packages`)
- **Package Store (`packages.Store`)**: Content-addressed offline cache at `~/.cache/micromax-sandbox/packages/` for wheel archives.
- **Pure-Python Wheel Extraction**: `packages.ExtractWheel` safely unpacks `.whl` archives into `/in/site-packages`, avoiding path traversal attacks.
- **Environment Integration**: `PYTHONPATH` automatically includes `/lib/python3.13:/in/site-packages`.
- **Offline Air-Gap Safety**: Requesting an uncached package in offline mode returns `sandbox.ErrPackageNotFound`.
- **CLI Management**:
  - `sandbox packages list [lang]`
  - `sandbox packages add --lang python <file.whl>`
  - `sandbox run --pkg "pkg1,pkg2" script.py`
